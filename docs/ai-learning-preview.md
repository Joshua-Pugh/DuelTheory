# AI Learning Preview

Opt in under Preferences → Allow AI learning preview, then start AI Practice. The duel header offers Review last AI move after an AI play. Pause AI freezes automatic progression while you inspect the board; Resume AI continues. Opening feedback also pauses automatic AI progression. Rate the move and optionally explain the alternative. Only the most recent substantive AI move is offered in-game; passing and automatic battle steps do not replace it.

This release collects local review data; it does not train a model, update policy weights, upload records or change the opponent automatically. The AI Practice setup provides counts, recent feedback, JSON export and deletion. No collection in private rooms or local two-seat duels. Defaults off; restoring defaults turns collection off. Turning collection off leaves existing records available for export/deletion and stops further writes.

Successful explicit actions and automatic single-action dispatches are recorded for both actors. Each example contains the actor-visible board, own hand, pile counts, legal alternatives (first 100 with original count), selected action, pilot version and optional heuristic rationale. Player phase-shortcut transitions are not recorded; response passes in AI mode are dispatched individually and are recorded. No shuffle seed, draw order, raw action descriptions, event log, chat or opponent-hidden identities are retained. Own deck order is never stored. Notes are user-supplied and may contain anything the user types; do not enter personal information. These are examples of the current policy's reasoning, not verified optimal decisions.

Natural game outcomes and concessions label retained examples by a unique game UUID. Abandoned page sessions remain unlabeled. Match result statistics remain in their separate existing local store. Retain at most 1,000 examples and 1.5 million JSON characters; older examples are evicted. Storage failures warn without stopping gameplay. Exports are manual downloads and may include private deck/hand information the actor knew; nothing is automatically sent to DuelTheory.

Next: review exported feedback, build held-out tactical decision scenarios, compare candidate policy changes with the existing pilot, and release changes only after rule, privacy and strategy validation. No automatic training pipeline exists in this preview.
