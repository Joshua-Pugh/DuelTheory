# A five-minute store demonstration

Use a laptop for the organizer and two phones for players. Open the website in the browser you will take to the store; organizer access belongs to that browser. Internet access is required. This is a real connected demo, not a slideshow.

1. **Set the room up.** Open Table Tools → Event Hub demo. Create four tables with two seats each. In Edit profile, choose starting life and a counter appropriate to the store's game. For a high-life demonstration, use 8,000 Life, taps of 100 and holds of 1,000. Nothing requires a trademarked preset.
2. **Hand over the invitation.** Select Table 1 and have each person scan its QR with their own phone. They enter nicknames and join. Show that the laptop's organizer did not take either seat. Table 1 changes from Waiting to Ready; the other three tables remain available.
3. **Start a round.** The Round panel automatically selects ready tables. Choose a short demonstration duration, then Start round 1. Both phones roll for first. The organizer sees In progress, the round clock and each player's totals. The QR is now under Show invitation, so it no longer takes the main space.
4. **Show ordinary play.** On one phone, enter a custom life deduction and adjust the configured counter. Inspect the other player on that phone: their totals are readable, but their controls are not yours. Watch the changes appear on the laptop within its two-second refresh.
5. **Request help.** A player taps Call organizer. The laptop identifies the table with an assistance badge. In Tell the room, select Table 1 only and send “I’m on my way.” Show the message on that phone, then clear the help request. An empty/unrelated table is unaffected.
6. **Resolve a mistake.** On the organizer laptop, expand Correct a total. Select the player, enter a signed adjustment and write a short explanation. Save it. Show the Organizer correction and explanation in the table history. The player's next ordinary change starts from the corrected total; they cannot undo the organizer's change with the last-entry shortcut.
7. **Finish without losing the game.** Choose Mark table finished. The overview now counts a finished table. Review & end round, then End & archive. Show that both phones are still connected to their finished table and that the final totals and history remain available. If you deliberately end unfinished games instead, confirmation and an explanation are required.
8. **Run it again.** Choose Prepare next round → Keep the same players. Both phones keep their seats, totals reset and round 2 opens a fresh roll when started. The QR never changes. For a new group, choose Free all seats and confirm the affected seats; the old players must join again.
9. **Show the record.** Open Completed rounds or Game history, then Download event history. The JSON contains the saved game records and organizer corrections. Only the organizer can download it. Three recent games appear in the panel; older archived games remain saved on the server and are included in the download.

Ask the store owner which of these steps would save them a walk across the room. Use that feedback before expanding table counts, building staff roles or adding tournament pairings.

## What this pilot does not replace

Player registration, Swiss pairings, standings, prize allocation and official result submission stay with the store's existing event process. The round clock does not enforce a game's tournament rules or automatically end games. Account-linked organizer access, staff permissions and a public organizer subscription are not part of this build.
