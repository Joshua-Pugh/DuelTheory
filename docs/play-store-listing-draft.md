Full description:

DuelTheory is a customizable companion for card games played at a physical table.

Choose a game profile or set your own starting life, resources, counters and defeat thresholds. Create a shared table and let players join with a room code or invite link. Each player enters their own changes from their phone.

Use the first-player die roll, turn timer and session history to keep the table organized. Save game configurations on your device for the next session.

This release focuses on tracking games played in person. It does not enforce a game's rules or automate card effects. An internet connection is required for shared tables.
