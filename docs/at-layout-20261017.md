# AT shared text layout — October 17, 2026

All AT cards now use the previously expanded layout: the smaller art opening and larger rules panel have fixed positions across card types, rather than changing with text length. The shared AshenCardFrame is used by the catalog, deck previews and Creator Studio.

Rules are top/left aligned with normal-weight prose. Recognized keyword terms remain bold, including inline keyword references. Leading keyword/reminder lines form a separate block with a half-em gap before following effects. Reminder text remains normal; flavor text remains italic. Resource glyphs and adaptive text fitting are preserved.

Only Units and Command Stations retain the stat ring. Stations extract the source `HP: 20` line into `HP 20` in the ring, removing the repeated line from the rules box. Missing HP is displayed as unknown, not guessed. Unit A/D remains unchanged. Relics, Runes, Tactics, Strategies and Ley Fonts use a separate ring-free lower frame with a taller rules panel and a full-width set footer.

CardMaterials builds that lower assembly from the existing 1060×1484 material layers using SVG source bands. The original full-width plaque becomes the lower footer, and mirrored side geometry removes the old ring overlap. Existing faction filters and fixed outer iron are preserved. No lower-resolution raster assets were generated and the originals were not edited.

Validation: 181 tests in 38 files passed. Browser checked all 91 catalog entries plus inspector: no rules-box overflow at the preview viewport, normal text weight 400 and left alignment. Checked Warband of Bloodfire beside Warband Overseer for shared art/type positions and keyword spacing; checked The Broken Fist Keep for HP 20. Production build passes (existing main-chunk size advisory remains).
