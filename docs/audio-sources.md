# Recorded audio sources

These are candidates, not sounds shipped in the current build.

- Kenney Casino Audio: https://kenney.nl/assets/casino-audio — 50 card, dice and chip recordings; CC0. Suitable for draws, shuffles, placements and tabletop rolls. License guidance: https://kenney.nl/support
- Sonniss GDC bundle: https://gdc.sonniss.com/ — recorded effects suitable for impacts, metal and fantasy ambience. Commercial use is allowed under the bundle license: https://sonniss.com/gdc-bundle-license/

Before adding a recording, save its source URL, original filename and license beside the asset. Trim and compress only the selected effects. Keep sound optional, unlock playback on a user gesture, and feed it from new game events rather than renders. Do not redistribute source libraries as standalone packs.
