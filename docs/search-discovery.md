# Search discovery

Both public sites use their canonical HTTPS root URL, allow crawling in robots.txt, and publish /sitemap.xml. The current DT application uses hash navigation; hash fragments are not separate sitemap pages. The AT landing page links to its rules/play page and private-room setup on DT.

Google Search Console URL-prefix ownership was verified on October 26, 2026 using each site's published HTML meta tag. Keep these verification tags in place. No Google credentials are stored in either repository.

AT social links refer to the Ashen Throne accounts, rather than implying they are separate DuelTheory accounts.

Sitemap submission and homepage indexing requests are managed through Google Search Console. A submission does not guarantee placement or ranking; use the URL Inspection and Pages reports to monitor Google's results.

Completed October 26, 2026: both sitemap submissions returned Success. URL Inspection reported both homepages already indexed, and refresh/indexing requests for both updated homepages were accepted into Google's priority crawl queue.
