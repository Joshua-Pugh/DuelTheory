# DuelTheory branding

Approved Forge Crest revision 03, adopted October 25, 2026.

The crest uses separated DT initials and a shallow gold bevel. The wordmark is Constantia Bold converted to SVG outlines. The assets contain no external font dependency or embedded raster images. The tagline is separate homepage text, not part of the crest or wordmark.

- public/branding/dt-forge-crest.svg — transparent crest used in the header, card backs, coin toss and game dialogs.
- public/branding/dt-wordmark.svg — outlined, beveled wordmark.
- public/branding/dt-forge-icon.svg — browser icon.
- public/branding/dt-forge-icon-180.png — Apple touch icon.
- public/branding/dt-forge-icon-512.png — raster icon master.

Forest #14382B; gold face ranges from #E0C57F through #C9A650 to #B38A3E. Vector artwork was developed with AI-assisted coding and reviewed at desktop and phone header sizes.
