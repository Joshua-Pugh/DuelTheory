# DuelTheory

DuelTheory is home to Ashen Throne and Table Companion. See the [roadmap](docs/platform-roadmap.md) and [deployment guide](docs/github-pages.md).

## Latest updates

All four updates are part of DuelTheory v3.9.3. Commit IDs identify the earlier changes within that version.

- **v3.9.3 · Contact and footer.** Added a dedicated contact page with email and bug-report links. Updated the About page and kept visited footer links dark green.
- **v3.9.3 · Ashen Throne gameplay.** Refine draws two cards and returns one to the bottom of the deck. Improved card selection dialogs and battlefield indicators, corrected Warhowl’s entry trigger, and gave Blood Cauldron a token trigger when a Brute damages an enemy Command Station.
- **v3.9.3 · Rules and starter decks (`e3d80ac`).** Added a dedicated rules page and keyword reference. Replaced the public deck builder with starter lists and made the Card Library read-only.
- **v3.9.3 · Unit readiness (`435ba77`).** Separated Unready from Fatigue so deployment and Exhaust restrictions apply independently.
