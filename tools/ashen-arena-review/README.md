# Local populated arena review

Run the existing Vite development server and open `/tools/ashen-arena-review/`. Review controls prepare attackers or blockers, or switch the inspected seat. Moves still go through `applyAshenCommand` and the real rules engine.

The position includes Ready and fatigued Units, Soar, Ranged, Standfast and a Spent Font. Use it to inspect legal highlights, scroll/resize connections, direct assignment/removal, multiple blocks, damage, destruction, result close/Escape and reduced motion.

This is a local developer surface. None of the public, mobile or private release entries import it, and asset preparation never copies `tools/` into a release. It neither loads user saves nor creates production rooms. It is not a gameplay mode.
